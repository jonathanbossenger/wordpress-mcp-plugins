## Other findings
- Some delete tools are permanent with no trash path. `aafm/wc-delete-product` always force-deletes (`includes/abilities/woocommerce/products.php:1440`); its docblock claims products have no recoverable trash, but WC products are posts and can be trashed. It is not in the high-risk lock list (`includes/audit/high-risk.php:30-38`). `delete-media` (`includes/abilities/media.php:1814`) and `delete-comment` (`includes/abilities/comments.php:1115`) are also permanent, but `moderate-comment` offers trash. This doesn't change SAFE-DELETE, which is about posts, but the review's summary doesn't mention it.
- The SEC-DEFAULT and SAFE-READONLY caveat about the adapter default server is accurate. This plugin's own tools are forced `mcp.public = false` (`includes/register.php:940`) and hard-blocked on that server. But in `auto` mode the bundled adapter will serve other plugins' public abilities to any logged-in user with `read`, with none of this plugin's logging, read-only or allowlist controls.
