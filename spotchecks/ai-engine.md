## Other findings
- Inconsistent scoring across reviews: STD-TRANSPORT is Partial here for `2025-06-18`, but cowboy-mcp, alphabridge-mcp, miniorange-secure-mcp-server and siteskite got Pass with the same version. Under the checklist wording ("current protocol version"), ai-engine's Partial is the correct one and those Passes look too generous.
- `mwai_vision` takes a local `path` argument (`labs/mcp-core.php:2858`), so an admin or bearer-token session can have the server read any file PHP can access and send it to the AI provider. Only limited sessions are blocked (`labs/mcp.php:1047-1050`). The review does not mention this. It is minor, since it is admin-only.
- The default `mcp_log_calls => true` (`constants/init.php:247`) suggests logging is on, but with no free writer the setting does nothing unless Pro is installed. This is consistent with the review's SAFE-LOG note.
