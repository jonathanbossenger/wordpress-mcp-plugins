## Other findings
- The wildcard claim in the review (SAFE-SCOPE summary and the notes, "wildcard scopes cannot grant them") is inaccurate. `*` grants privileged tools (wp_cli_run, search-replace, files) once an admin enables the group. Only glob patterns and the role presets exclude them (`includes/auth/class-permission-guard.php:22-24`, `includes/admin/class-access-presets.php:192-194`). Privileged tools also refuse to run unless the audit log and change history are both on (`includes/mcp/class-server.php`, `privileged_refusal`).
- The REST passthrough tools (`wp_rest_write`/`wp_rest_delete`) require only the `read` capability, not `manage_options`, and are off by default (`includes/tools/rest/class-rest-delete.php:41-43`). Once enabled, a key is limited only by each route's own permission check, as the review's notes say.
